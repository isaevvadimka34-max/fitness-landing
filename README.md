# Fitness Landing

Это простой статический лендинг для продажи фитнес-курса.

Проект сделан для первого этапа: здесь создана только базовая архитектура без дизайна, сложной логики и интеграций.

## Как открыть проект

Откройте файл `index.html` в браузере.

Для текущей версии не нужен сервер, сборщик, backend или установка зависимостей.

## Структура проекта

- `index.html` — главная страница лендинга.
- `assets/css/style.css` — базовые CSS-настройки.
- `assets/js/main.js` — базовый JavaScript-файл для будущего безопасного поведения интерфейса.
- `assets/img/hero/` — будущие изображения первого экрана.
- `assets/img/results/` — будущие изображения результатов.
- `assets/img/reviews/` — будущие изображения отзывов.
- `assets/img/tariffs/` — будущие изображения тарифов.
- `assets/img/icons/` — будущие иконки.
- `assets/docs/` — будущие юридические документы.
- `AGENTS.md` — правила работы для Codex.
- `PROJECT_RULES.md` — правила бренда, структуры лендинга и будущей оплаты.
- `.gitignore` — список файлов, которые не нужно добавлять в Git.

## Оплата и заявки

В будущем выбор тарифа будет вести к официальной форме или виджету GetCourse.

Данные заявок, статусы оплат и работа отдела продаж должны храниться и обрабатываться в GetCourse, а не в файлах сайта.
